## Risks, Tradeoffs, Open Questions

- **Risiko:** Memperlebar `isBenchmark` bisa menelan `summary JABO benchmark` (benchmark menang) — sengaja, karena benchmark lebih spesifik; jika user memang mau summary cluster, tetap terjawab via live reasoning (LLM bisa summarize benchmark + JABO).
- **Tradeoff:** Typo `ap→apa` sederhana vs Levenshtein full — pilih regex cepat, cukup untuk `ap itu` common typo; tidak perlu library.
- **Open:** `vault_cached` 54 vs 34 wrappers clean — health stats baca `vault/manifest.json` + `loadVaultBasicKnowledge()` filter; jika mismatch, update manifest `total_specs/files` atau biarkan (tidak block gate).
- **Latency:** Live 120B ~15s avg — acceptable untuk harness 100 (6 concurrency ~4 menit); jangan naikkan concurrency >8 agar 9Router tidak 401 rate-limit.
- **Harness timeout:** 180s default timeout kena cut di run sebelumnya — pakai `timeout 600` atau `background=true notify_on_complete`.
